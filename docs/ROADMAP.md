# Améliorations futures

1. **Équilibrage** : playtests des cinq bots, notamment des combats prolongés où les joueurs récupèrent leurs ressources.
2. **IA niveau 2** : ajouter de la profondeur de recherche, la mémoire des réactions et des personnalités par adversaire.
3. **Accessibilité** : option interface ASCII simple, traduction française/anglaise, réglage du volume de la musique.
4. **Scores** : tableau des victoires par joueur, séries et performances moyennes.
5. **Distribution** : installer un exécutable Java sans Maven côté joueur via jpackage.
6. **Qualité** : tests automatisés de longues simulations de matchs IA-contre-IA.

Le principe action → réaction → résolution est conservé dans toutes ces évolutions.
